# Планировщик задач

Веб-приложение на Go для управления задачами с поддержкой повторений и поиска. В основе — стандартная библиотека `net/http` и SQLite без лишних зависимостей.

## API

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/api/nextdate` | Вычислить следующую дату повторения |
| `GET` | `/api/tasks` | Список задач (поиск: `?search=текст`) |
| `POST` | `/api/task` | Создать задачу |
| `GET` | `/api/task?id=` | Получить задачу по ID |
| `PUT` | `/api/task` | Обновить задачу |
| `DELETE` | `/api/task?id=` | Удалить задачу |
| `POST` | `/api/task/done?id=` | Отметить задачу выполненной |

## Правила повторения

| Правило | Пример | Описание |
|---------|--------|----------|
| `y` | `y` | Ежегодно |
| `d N` | `d 7` | Каждые N дней, от 1 до 400 |

## База данных

Таблица `scheduler`:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `INTEGER` | Первичный ключ |
| `date` | `CHAR(8)` | Дата в формате `YYYYMMDD` |
| `title` | `VARCHAR(256)` | Название задачи |
| `comment` | `TEXT` | Комментарий |
| `repeat` | `VARCHAR(128)` | Правило повторения |

## Переменные окружения

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `TODO_PORT` | `7540` | Порт сервера |
| `TODO_DBFILE` | `scheduler.db` | Путь к файлу БД |

## Задания со звёздочкой

Задания повышенной трудности не выполнялись:

- правила повторения `w` (еженедельно) и `m` (ежемесячно) — не реализованы
- аутентификация через JWT и переменная `TODO_PASSWORD` — не реализована

## Запуск

```bash
go run .
```

Сервер поднимается на `http://localhost:7540`, база создаётся автоматически.

## Тесты

Сначала запустить сервер, затем в отдельном терминале:

```bash
go test ./tests
```

## Docker

```bash
docker build -t todo-scheduler .

docker run -d -p 7540:7540 \
  -v ~/scheduler-data:/data \
  -e TODO_DBFILE=/data/scheduler.db \
  todo-scheduler
```

# 📅 Go Scheduler

Веб-приложение на **Go** для управления задачами с поддержкой повторений, поиска и хранения данных в **SQLite**.

Проект построен на стандартном HTTP-сервере Go и разделён на отдельные компоненты для обработки HTTP-запросов, работы с базой данных и конфигурации приложения.

## ✨ Возможности

- ➕ Создание задач
- 🔎 Получение задач по идентификатору
- 📋 Получение списка задач
- 🔍 Поиск задач по названию и комментарию
- 📅 Поиск задач по дате
- ✏️ Редактирование задач
- 🗑️ Удаление задач
- ✅ Отметка задач как выполненных
- 🔄 Поддержка повторяющихся задач
- 📆 Вычисление следующей даты выполнения
- ⏰ Автоматическая обработка просроченных задач
- 🗄️ Хранение данных в SQLite
- 🌐 Веб-интерфейс
- 🐳 Запуск в Docker
- ⚙️ Автоматизированное тестирование через GitHub Actions

## 🏗️ Архитектура

Проект разделён на несколько логических компонентов.

### API

Пакет `pkg/api` отвечает за HTTP API приложения:

- обработку входящих запросов;
- маршрутизацию;
- валидацию данных;
- работу с задачами;
- обработку повторений;
- формирование HTTP-ответов и ошибок.

### Database

Пакет `pkg/db` отвечает за взаимодействие с SQLite:

- инициализацию базы данных;
- создание структуры таблиц;
- создание индексов;
- добавление задач;
- получение задач;
- обновление задач;
- удаление задач;
- поиск и выборку задач.

### Environment

Пакет `pkg/env` отвечает за получение конфигурации из переменных окружения с использованием значений по умолчанию.

### Web

Каталог `web` содержит клиентскую часть приложения:

- HTML
- CSS
- JavaScript
- страницы пользовательского интерфейса

## 🌐 REST API

| Метод | Endpoint | Назначение |
|---|---|---|
| `GET` | `/api/nextdate` | Вычисление следующей даты повторения |
| `GET` | `/api/tasks` | Получение списка и поиск задач |
| `POST` | `/api/task` | Создание задачи |
| `GET` | `/api/task` | Получение задачи |
| `PUT` | `/api/task` | Обновление задачи |
| `DELETE` | `/api/task` | Удаление задачи |
| `POST` | `/api/task/done` | Отметка задачи выполненной |

API использует **JSON** для передачи данных задач и возвращает соответствующие HTTP-статусы в зависимости от результата обработки запроса.

## 🔄 Повторение задач

В текущей версии поддерживаются два типа повторения:

- `y` — ежегодное повторение
- `d N` — повторение через заданное количество дней

Для дневного интервала используется диапазон от **1 до 400 дней**.

При выполнении повторяющейся задачи система автоматически вычисляет следующую дату.

## 📅 Работа с датами

Приложение выполняет валидацию дат при создании и изменении задач.

Если дата не указана, используется текущая дата.

Для задач с датой в прошлом выполняется автоматическая корректировка:

- одноразовая задача переносится на текущую дату;
- повторяющаяся задача получает следующую дату согласно установленному правилу.

## 🗄️ База данных

Для хранения задач используется **SQLite**.

Основная сущность проекта — таблица `scheduler`, содержащая:

- идентификатор задачи;
- дату выполнения;
- название;
- комментарий;
- правило повторения.

Для ускорения операций, связанных с датами задач, используется индекс.

Локальная SQLite-база исключена из Git через `.gitignore`.

## 🚀 Запуск

Проект можно запускать локально с помощью Go.

При запуске приложение:

1. Инициализирует SQLite.
2. Создаёт необходимые структуры базы данных.
3. Регистрирует HTTP-маршруты.
4. Подключает веб-интерфейс.
5. Запускает HTTP-сервер.

По умолчанию приложение использует порт `7540`.

Для запуска выполните:

    go run .

## 🐳 Docker

Проект содержит `Dockerfile` для запуска приложения в контейнере.

Docker-образ включает:

- собранное Go-приложение;
- веб-интерфейс;
- необходимые runtime-компоненты.

Сборка образа:

    docker build -t go-scheduler .

Запуск контейнера:

    docker run --rm -p 7540:7540 go-scheduler

SQLite-база может храниться во внешнем volume, что позволяет сохранять данные между перезапусками контейнера.

Текущая реализация поддерживает ограниченный набор правил повторения:
